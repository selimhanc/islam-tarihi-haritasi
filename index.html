Harita API anahtarı

Klasik görünümlü harita için Google Maps JavaScript API anahtarı gerekir. Anahtarınız yalnızca bu tarayıcıda saklanır (sunucuya gönderilmez).

  1. Google Cloud Console → proje oluşturun (veya mevcut projeyi seçin).
  2. APIs & Services → Library: Maps JavaScript API etkinleştirin.
  3. Credentials → Create credentials → API key ile anahtar alın.
  4. Anahtarı aşağıya yapıştırın. Web sitesi kısıtını kullanacaksanız file:// için tarayıcı referansı yerine IP kısıtlaması ya da kısıtsız anahtar kullanın.
Anahtar geçersiz veya Maps JavaScript API etkin değilse harita yüklenmez; hata mesajı gösterilir.
